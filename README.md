## A few things I've built

- **[NeuroWorm](https://github.com/sanjayBahadur/NeuroWorm)** — Can a simulated worm nervous system play Snake? An experiment with the *C. elegans* connectome and what its wiring actually contributes.
- **[AlfredML](https://github.com/sanjayBahadur/AlfredML)** — A local assistant for asking questions about your own documents, using Ollama and retrieval-augmented generation.
- **[Retention Radar](https://github.com/sanjayBahadur/retention-radar)** — When do grocery shoppers start drifting away? An analysis of shopping patterns, churn risk, and retention ideas worth testing. [Explore the findings](https://sanjaybahadur.github.io/retention-radar/).
- **[Space Defenders](https://github.com/sanjayBahadur/SPACE-DEFENDERS-21st-Century)** — A browser game you control with hand gestures. [Play it here](https://spacedefenders.sanjaymalla.com).

<details>
<summary>Hardware, research, and other experiments</summary>

- **Radar research at USF:** Python signal processing for TI mmWave/DCA1000 experiments, connecting radar captures to model evaluation.
- **MeshUSF / Uni-Fi:** An ongoing LoRa/BLE prototype for two phones to share one companion radio with separate offline message histories. Physical radio testing is still in progress.
- **[UEFI Dino](https://github.com/sanjayBahadur/uefi_dino):** A dinosaur runner in C that boots before the operating system. I also explore [EEG hardware interfaces](https://github.com/sanjayBahadur/EEG-prosthetic-interface).

Other experiments take me into [post-quantum cryptography](https://github.com/sanjayBahadur/pqpake-artifact) and [developer tools](https://github.com/sanjayBahadur/AFK-orchestrator). I like having something I can run, test, or play with while I work an idea out.
